# 👾 Alien Invasion (Pygame)

A simple 2D arcade-style **Alien Invasion game** built with **Python and Pygame**.  
The player controls a spaceship that shoots bullets to destroy waves of invading aliens.

This project demonstrates the basics of **game development with Pygame**, including sprite movement, collision detection, keyboard controls, scoring, and game states.

---

## 🎮 Game Preview

The player controls a spaceship at the bottom of the screen and must destroy incoming alien fleets.

Features include:
- Spaceship movement
- Bullet firing
- Alien fleet generation
- Collision detection
- Score tracking
- Increasing difficulty

---

## 🚀 Features

- 🛸 Player-controlled spaceship
- 👽 Multiple aliens appearing in fleets
- 🔫 Shooting bullets to destroy aliens
- 💥 Collision detection between bullets and aliens
- ❤️ Limited lives
- 📈 Scoreboard system
- ⚡ Increasing speed as levels progress

## 📦 Installation

1. **Clone the repository**

```bash
git clone https://github.com/yourusername/alien-invasion.git
```

2. **Navigate into the project directory**

```bash
cd alien-invasion
```

3. **Install dependencies**

```bash
pip install pygame
```

---

## ▶️ Run the Game

```bash
python alien_invasion.py
```

---

## 🎯 Controls

| Key | Action |
|----|------|
| ⬅️ Left Arrow | Move ship left |
| ➡️ Right Arrow | Move ship right |
| Space | Fire bullet |
| Q | Quit game |
